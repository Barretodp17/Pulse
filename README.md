# PULSE - Blog Musical

PULSE es un blog musical creado como proyecto académico de la Academia RollingCode.

El proyecto busca crear un espacio para descubrir noticias, historias, tendencias y contenidos relacionados con el mundo de la música.

---

##  Descripción

PULSE reúne diferentes secciones relacionadas con la música, entre ellas:

- Entradas y artículos musicales.
- Noticias.
- Galería de imágenes.
- Categorías musicales.
- Contenido multimedia.
- Formularios de contacto y comentarios.
- Página de error 404.

El sitio fue desarrollado con un diseño moderno, responsive y adaptado a diferentes tamaños de pantalla.
